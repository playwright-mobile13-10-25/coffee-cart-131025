**Additional Context**
This test validates the intentional performance degradation feature that slows down cart operations when more than 7 items are in the cart. This is a deliberate feature for demonstration and testing purposes, not a bug. Documentation states: "The add to cart process will be slowing down (intentionally) when the cart has more than 7 items."
