**Test Case ID**
TC-011

**Title**
Verify Cart Persistence Between Pages

**Related Requirement/User Story**
Cart state management functionality

**Date Created**
11-12-2024

**Author**
QA Team

**Priority**
Medium

**Preconditions**
1. User is on https://coffee-cart.app homepage
2. Cart is initially empty
3. Coffee menu is loaded

**Test Steps**
| Step # | Step Description | Test Data | Expected Result |
|:------:|:----------------|:----------|:---------------|
|   1    | Add Espresso to cart from homepage | Coffee: Espresso | Cart count shows 1, total $10.00 |
|   2    | Add Cappuccino to cart | Coffee: Cappuccino | Cart count shows 2, total $29.00 |
|   3    | Verify cart total on homepage | Expected: $29.00 | Pay button shows "Total: $29.00" |
|   4    | Navigate to cart page | N/A | Cart page opens |
|   5    | Verify both items appear in cart page | Items: Espresso, Cappuccino | Both items are listed |
|   6    | Verify cart total on cart page | Expected: $29.00 | Total shows $29.00 |
|   7    | Navigate back to homepage (using back button or menu) | N/A | Homepage loads |
|   8    | Verify cart count persists | Expected: 2 | Cart count still shows 2 |
|   9    | Verify cart total persists | Expected: $29.00 | Pay button still shows "Total: $29.00" |
|   10   | Add another item (Mocha) from homepage | Coffee: Mocha | Cart updates to 3 items |
|   11   | Verify cart total updates | Expected: $37.00 | Pay button shows "Total: $37.00" |
|   12   | Navigate to cart page again | N/A | Cart page opens |
|   13   | Verify all three items are present | Items: Espresso, Cappuccino, Mocha | All three items listed |
|   14   | Verify quantities are correct | N/A | Each item shows quantity of 1 |

**Postconditions**
Cart maintains state with 3 items totaling $37.00 across page navigation

**Status**
Not Run

**Environment**
- OS: Windows 10/macOS/Linux
- Browser: Chrome 119+, Safari 17+, Firefox 120+
- Version: Latest stable

**Screenshots**
If applicable, add screenshots showing cart persistence.

**Additional Context**
This test validates that the cart state is properly maintained when navigating between different pages of the application using Vuex state management.
