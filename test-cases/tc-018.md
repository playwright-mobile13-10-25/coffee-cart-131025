**Related Requirement/User Story**

**Preconditions**

| Step # | Step Description | Test Data | Expected Result |
|:------:|:----------------|:----------|:---------------|
|   1    | Verify cart is empty | N/A | Cart count is 0 |

|   3    | Verify no promotional popup appears | N/A | No popup is displayed |

|   7    | Verify promotional popup appears | N/A | Promotional modal/dialog is displayed |
|   8    | Verify popup shows discounted coffee | Expected: (Discounted) Mocha | Promo shows discounted coffee offer |
|   9    | Verify popup has close button | N/A | Close or dismiss button is visible |
|   10   | Close the promotional popup | N/A | Popup dismisses |
|   11   | Add fourth coffee item (Flat White) | Coffee: Flat White | Item added, cart count = 4 |
|   12   | Verify no popup appears | N/A | No popup for 4th item |
|   13   | Add fifth coffee item (Cappuccino) | Coffee: Cappuccino | Item added, cart count = 5 |

|   16   | Verify promotional popup appears again | N/A | Popup appears for every 3rd item (3, 6, 9...) |
