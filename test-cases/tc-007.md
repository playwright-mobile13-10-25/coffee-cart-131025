|   4    | Verify dialog message content | Expected text | Dialog asks "Add Espresso Con Panna to the cart?" |
|   5    | Verify dialog has "Yes" button | N/A | "Yes" button is visible and clickable |
|   6    | Verify dialog has "No" button | N/A | "No" button is visible and clickable |
|   7    | Click "No" button | N/A | Dialog closes without adding item |
|   8    | Verify cart remains empty | N/A | Cart count is still 0 |
|   9    | Right-click on "Espresso Con Panna" again | Coffee: Espresso Con Panna | Dialog appears again |
|   10   | Click "Yes" button | N/A | Dialog closes and item is added |
|   11   | Verify cart count updates | N/A | Cart count shows "1" |
|   12   | Verify cart total updates | Expected: $14.00 | Pay button shows "Total: $14.00" |
|   13   | Verify confirmation feedback | N/A | Visual feedback confirms addition |
