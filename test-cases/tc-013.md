**Test Case ID**
TC-013

**Title**
Hover Over Pay Button to Preview Cart (Desktop)

**Related Requirement/User Story**
Cart preview on hover functionality

**Date Created**
11-12-2024

**Author**
QA Team

**Priority**
Medium

**Preconditions**
1. User is on https://coffee-cart.app homepage
2. Using desktop browser with screen width >= 800px
3. Cart contains items: Mocha (qty: 1), Flat White (qty: 2)
4. Total cart value is $44.00

**Test Steps**
| Step # | Step Description | Test Data | Expected Result |
|:------:|:----------------|:----------|:---------------|
|   1    | Verify Pay button is visible at bottom right | N/A | Pay button displays "Total: $44.00" |
|   2    | Verify cart preview is not visible initially | N/A | No cart preview is shown |
|   3    | Move mouse cursor to hover over Pay button | N/A | Cursor hovers over the button |
|   4    | Wait for hover effect to activate | Wait: 0.5 seconds | Hover effect activates |
|   5    | Verify cart preview panel appears | N/A | Cart preview popup/tooltip appears |
|   6    | Verify preview shows "Mocha" item | Coffee: Mocha | Mocha is listed in preview |
|   7    | Verify Mocha quantity and price | Expected: $8.00 x 1 | Display shows correct info |
|   8    | Verify preview shows "Flat White" item | Coffee: Flat White | Flat White is listed |
|   9    | Verify Flat White quantity and price | Expected: $18.00 x 2 | Display shows correct info |
|   10   | Verify preview shows cart total | Expected: $44.00 | Total displays correctly |
|   11   | Verify preview has + and - buttons for items | N/A | Increment/decrement buttons visible |
|   12   | Click "+" button for Mocha in preview | N/A | Mocha quantity increases to 2 |
|   13   | Verify cart total updates in preview | Expected: $52.00 | Total updates to $52.00 |
|   14   | Move cursor away from Pay button | N/A | Cart preview disappears |

**Postconditions**
Cart contains Mocha (qty: 2) and Flat White (qty: 2), total is $52.00

**Status**
Not Run

**Environment**
- OS: Windows 10/macOS/Linux
- Browser: Chrome 119+, Safari 17+, Firefox 120+
- Version: Latest stable
- Screen: Desktop (1920x1080 minimum)
- Device: Mouse required (not touch)

**Screenshots**
If applicable, add screenshots showing cart preview on hover.

**Additional Context**
This test validates the desktop-only feature where hovering over the Pay button displays a quick cart preview with the ability to modify quantities without navigating to the cart page.
