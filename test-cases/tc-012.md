**Test Case ID**
TC-012

**Title**
Double-Click to Translate Coffee Name to Chinese

**Related Requirement/User Story**
Translation feature functionality

**Date Created**
11-12-2024

**Author**
QA Team

**Priority**
Low

**Preconditions**
1. User is on https://coffee-cart.app homepage
2. Coffee menu is fully loaded
3. All coffee names are displayed in English

**Test Steps**
| Step # | Step Description | Test Data | Expected Result |
|:------:|:----------------|:----------|:---------------|
|   1    | Locate "Espresso" coffee item | Coffee: Espresso | Item is visible with English name |
|   2    | Verify initial name is in English | Expected: "Espresso" | Name displays as "Espresso" |
|   3    | Double-click on the "Espresso" text | N/A | Double-click is registered |
|   4    | Verify name translates to Chinese | Expected: "特浓咖啡" | Name changes to Chinese characters |
|   5    | Verify price remains unchanged | Expected: $10.00 | Price still shows $10.00 |
|   6    | Locate "Cappuccino" coffee item | Coffee: Cappuccino | Item is visible |
|   7    | Double-click on "Cappuccino" text | N/A | Double-click is registered |
|   8    | Verify name translates to Chinese | Expected: "卡布奇诺" | Name changes to Chinese characters |
|   9    | Locate "Americano" coffee item | Coffee: Americano | Item is visible |
|   10   | Double-click on "Americano" text | N/A | Double-click is registered |
|   11   | Verify name translates to Chinese | Expected: "美式咖啡" | Name changes to Chinese characters |
|   12   | Double-click on "Espresso" Chinese name again | Coffee: Espresso (特浓咖啡) | Double-click registered |
|   13   | Verify name toggles back to English | Expected: "Espresso" | Name changes back to "Espresso" |
|   14   | Add translated Cappuccino to cart | Coffee: Cappuccino (卡布奇诺) | Item added with Chinese name |

**Postconditions**
Coffee names can be toggled between English and Chinese, translation state persists for each item independently

**Status**
Not Run

**Environment**
- OS: Windows 10/macOS/Linux
- Browser: Chrome 119+, Safari 17+, Firefox 120+
- Version: Latest stable
- Font: Chinese character support required

**Screenshots**
If applicable, add screenshots showing translation feature.

**Additional Context**
This test validates the special double-click translation feature that allows users to see coffee names in Chinese characters. This is a unique easter egg feature of the application.
