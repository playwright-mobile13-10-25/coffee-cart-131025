# coffee-cart

## Test Cases

This repository contains 20 comprehensive test cases for the Coffee Cart application (https://coffee-cart.app).

### Quick Start

All test cases are located in the `test-cases/` directory. Each test case follows the ISTQB template format and includes at least 10 detailed steps.

### Creating GitHub Issues

To create GitHub issues from the test cases:

```bash
# Method 1: Use the provided script (requires GitHub CLI)
./create-issues.sh

# Method 2: Create issues manually
# See test-cases/README.md for detailed instructions
```

### Test Coverage

The 20 test cases cover:
- ✅ Product display and navigation
- ✅ Add to cart functionality (including right-click menu)
- ✅ Cart management (add, remove, update quantities)
- ✅ Special features (translation, hover preview)
- ✅ Payment and checkout
- ✅ Promotional offers
- ✅ Performance testing
- ✅ Responsive design

For detailed information about each test case, see [test-cases/README.md](test-cases/README.md).
